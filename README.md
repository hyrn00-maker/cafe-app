
# CafeSnap ☕

チェーンカフェの情報を簡単に探せるWebアプリです。

## アプリ概要

スターバックス、タリーズコーヒー、サンマルクカフェの情報を一覧で確認できます。

カフェ名で検索したり、各カフェの公式サイトにアクセスしたりできます。

## 開発した背景

複数のチェーンカフェの情報をまとめて確認できるアプリがあれば便利だと考え、制作しました。

## 主な機能

- チェーンカフェの一覧表示
- カフェ名による検索
- 各カフェの公式サイトへのリンク

## ローカル環境での起動方法

1. このリポジトリをダウンロードまたはクローンする
2. プロジェクトのフォルダで以下を実行する

```bash
npm install
npm run dev
```

3. ターミナルに表示されたローカルURLをブラウザで開く
