
# CafeSnap ☕

## GitHubリポジトリ
https://github.com/hyrn00-maker/cafe-app

カフェチェーンの情報を簡単に探せるWebアプリです！

## アプリ概要

スターバックス、タリーズコーヒー、サンマルクカフェの情報を一覧で確認できます。

カフェ名で検索したり、各カフェの公式サイトにアクセスしたりできます。

## 開発した背景

スターバックスやタリーズなど、チェーンカフェの新作や期間限定の商品を見るのが好きなので、いろいろなカフェの情報をまとめて見られるアプリがあったら便利だと思いました。

利用者が写真を投稿して、それを見た人が「これおいしそう！」「今度買ってみたい！」と思える、感想を共有できるアプリを作りたいと考えました。

現在はチェーンカフェの一覧表示や検索、公式サイトへのリンク機能までですが、今後は新作や期間限定商品の情報を表示したり、利用者がカフェの写真や感想を投稿できるアプリを目指しています。

## 主な機能

- チェーンカフェの一覧表示
- カフェ名による検索
- 各カフェの公式サイトへのリンク


## 使用技術

- React
- JavaScript
- HTML / CSS
- Vite

## ローカル環境での起動方法

1. このリポジトリをダウンロードまたはクローンする
2. プロジェクトのフォルダで以下を実行する

```bash
npm install
npm run dev
```

3. ターミナルに表示されたローカルURLをブラウザで開く
